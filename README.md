# BackupBuddy

> Browser backup utility — backup, restore, and manage your browser data effortlessly.

## Features

- Backup browser bookmarks, history, and settings
- Restore from a previous backup with one click
- Schedule automatic reminders for regular backups
- Download backups as portable JSON or HTML files
- Import and merge backups from different browsers
- Preview backup contents before restoring
- Encrypt backups with a passphrase for extra security
- Compress backup files to save storage space
- Cross-browser compatible (Chrome, Firefox, Edge)

## Why BackupBuddy?

BackupBuddy operates entirely in your browser — your data is processed locally and never leaves your machine. Backups are saved as downloadable files that you control. There are no servers involved, no accounts to create, and no limits on how many backups you keep. It's free, private, and gives you peace of mind.
